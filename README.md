This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## About the project

This project use Next.js 16. It also uses Tailwind CSS for styling and Prisma as the ORM for database interactions. The project is structured to follow best practices for scalability and maintainability.
as Database it uses PostgreSQL from Neon, and the Prisma schema is defined in the `prisma/schema.prisma` file.
